# Decisions

One file per pull request that makes a design decision: `<issue>-<topic>.md`, for example
`14-export-csv.md` (`process-<topic>.md` when there is no issue). The PR adds it; nobody edits
another PR's file except to correct it. Because no two PRs touch the same file, they never conflict.

What goes in: the choices a later session would otherwise have to rediscover — which class holds
the rule, why this way and not the obvious other way, known limits, what was checked. Short
bullets. Not the steps of the work.

Search this folder by issue number or class name; don't read it whole.
